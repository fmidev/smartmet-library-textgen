# Header type "from_until"

Produces a header of the form "Odotettavissa tiistai-illasta torstaiaamuun". The clock times select the time of day; the end time accepts the same hours as the [until](header_until.md) header, the start time any hour (midnight, after midnight, morning, forenoon, noon, afternoon, evening or before midnight). Generally used with the corresponding period type "from_until".

The header type `from_until_weekday` produces the same header.

Possible headers are:

1. "Odotettavissa maanantaiaamusta maanantaiaamuun" and variations

In Swedish:

1. "Utsikter från måndag morgon till måndag morgon" and variations

In English:

1. "Expected weather from Monday morning until Monday morning" and variations
